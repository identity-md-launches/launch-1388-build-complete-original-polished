# Asset provenance and attribution

- **Original work for this assignment:** game and level design, all ASCII frog/environment/enemy/boss/effect art, terminal UI, favicon, 1200×630 SVG cover, and all synthesized music/effect sequences. Art is authored in `web/src/render.ts`, `web/src/engine.ts`, `web/index.html` and `scripts/create-cover.mjs`. The cover is a self-contained vector/text asset; its display font is embedded. No reference image, stock image, emoji artwork, hosted model output or third-party sound recording is used.
- **Space Mono**, regular and bold Latin WOFF2: distributed through `@fontsource/space-mono` 5.2.9, SIL Open Font License 1.1. Original copyright/license text is retained in `licenses/Space-Mono-OFL.txt`.
- **Silkscreen**, regular Latin WOFF2: distributed through `@fontsource/silkscreen` 5.2.8, SIL Open Font License 1.1. Original copyright/license text is retained in `licenses/Silkscreen-OFL.txt`. Its embedded cover use retains the same license attribution.
- TypeScript, Vite, Playwright and axe are development/test dependencies referenced through the lockfile. No third-party game engine is shipped. The JavaScript runtime uses browser Canvas, Web Audio, DOM and Pointer Events APIs.

The name, Pepe theme and arcade destination follow the request. This deliverable makes no claim of affiliation, official endorsement, arcade submission or admin approval.

Design review used the assignment's pinned **Better Interface** guide, adapted from Jakub Krehel's [Better Interface](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e/skills/better-interface), commit `267330e1adfc66a718fb65fa6918c1f06d0a689e` (MIT).
